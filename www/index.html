Reduction Stepper

This is my work in progress reduction stepper. In order to use it, simply enter a sequence of sml val declarations into the text box and hit enter formula. The expression which is about to be evaluated will be highlighted in yellow. In the event a substitution takes place, it will be highlighted green.
A couple notes
1. you can only use the `val`/`val rec`/`fun` keyword for declarations
2. lambda's and must have their arguement type annotated and `val rec` must have the entire type annotated (my typechecker is not smart enough to infer types yet)
3. I support the following expressions: int constansts, bool constansts, +, -, ~, *, div, mod, comparisions, andalso, orelse, if...then...else, let...in...end, tuples, match expressions, lambdas, and function application
4. Pattern match should work for int constanst, bool constansts, tuples, wildcards, and identifiers. It should also work within lamdas (though the first arguement must still be type annotated)
5. For recursive lambda's I will sometimes rename the underlying symbol to make sure it is unique after the `val rec` is consumed.
6. the `fun` keyword will be elaborated into val/val rec as required. It also requires it's first clauses types annotated (and the return type if it is a recursive function)
As an example:
val (x, z) = (5+ 5, 5 - 4)
val y = let val x = 5 in x * z end
val z = x + y

val rec fact : int -> int = fn 0 : int => 1 | x => x * fact (x - 1)
val a = fact 1
val b = fact 2
val x = let val rec fact : int -> int = fn 0 : int => 0 | x => 1 + fact (x - 1) in fact 3 end

fun fib (0 : int) : int = 1
| fib 1 = 1
| fib n = fib (n - 1) + fib (n - 2)
val _ = fib 3
fun curriedAdd (x : int) (y : int) = x + y
val _ = curriedAdd 1 2
